# פרוייקט עין-צופיה

## Database

### MongoDB
בחרתי בmongoDB בגלל הגמישות להוסיף שדות במקרה של הרחבת המערכת

## Status Code

200(ברירת מחדל) - במקרה של הצלחה

201 - במקרה של הצלחה ביצירה

204 - לא השתמשתי למקרה של הצלחה במחיקה כי החזרתי את המידע שנמחק

400 - למקרים בהם הגיע מידע לא תקין מהשרת

401 - למקרים בהם המשתמש לא קיבל גישה כי היה חסר לו מידע או שהוא הביא מידע לא תקין

403 - למקרים בהם המשתמש ניסה לבצע פעולה שהוא לא היה מורשה

404 - למקרים בהם המידע לא נמצא בבסיס הנתונים

409 - למקרים בהם הייתה סתירה בין המידע שהתקבל למידע הקיים במערכת

## Validation Rules

במקרה של קלט לא תקין השרת זורק שגיאה בהתאם למה שהוגדר (400,401,403)
